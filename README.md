# MindSync — 心有灵犀

无需注册的双人在线词语联想游戏。

## 玩法

1. 创建房间，把邀请链接或四位房间码发给朋友。两人到齐后由房主开始。
2. 第一轮自由联想。两人各自提交一个词，双方提交后一起揭晓。超时未提交也会计入一轮。
3. 两个词相同就获胜。否则，用最近一组双方都提交的词继续联想，直到匹配成功或用完回合。还没有完整词语对时，继续自由联想。

默认每轮 30 秒、最多 15 轮，房主可以在开局前调整。结算后可在「历史记录」查看对局。

## 安装与启动

安装 **Node.js 24 LTS**，在项目根目录运行：

```bash
npm ci
npm run dev
```

打开 [http://localhost:3000](http://localhost:3000)。本机测试双人对局时，第二位玩家可以用无痕窗口加入。首次启动会自动创建 `./mindsync.db`，可在 `.env.local` 中用 `DATABASE_PATH` 修改路径。

要在服务器上运行，参考 [配置示例](.env.example) 创建 `.env.local`，将 `PUBLIC_BASE_URL` 设为实际的 HTTPS 地址。然后执行：

```bash
npm run build
npm run start
```

将反向代理指向应用端口（默认 `3000`），并为 `/socket.io/` 启用 WebSocket 转发。
